# PRODIGY_DS_01

## Titanic Data Visualization Dashboard

This project is part of my Data Science Internship at Prodigy InfoTech.

### Project Objective
Create visualizations using Python to analyze Titanic passenger data.

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

### Visualizations Included
- Age Distribution Histogram
- Gender Distribution Pie Chart
- Passenger Analysis Dashboard

### Output
The dashboard provides insights into:
- Passenger age distribution
- Male vs Female passengers
- Average age
- Total passengers
